## Integration findings

`git merge-tree --write-tree` completed successfully with no textual conflicts. Only `docs/DETAILS.md`, `serve/server.py` and `serve/web/app.js` changed on both sides. The resulting source was exported to `C:\AI\Strata-upstream-review-20261017`, an isolated uncommitted snapshot; stable and live did not receive upstream code.

The candidate raises the setup minimum native engine to 0.1.45 ([`a08db82d`](https://github.com/Niko1221/Strata/commit/a08db82d)). Treat the server/native update as a coordinated build and validation task. Review new model-card sampling against our registry/model switching and private saved settings, prompt-token caching against model switches, answer-room behavior against our final tool-free pass, and native caching against image unload/save/restore. Clean textual merging does not resolve these behavioral questions.

**Confirmed integration blocker: tokenizer-bound prompt cache survives model switching.** Upstream `Service.prompts` is a `PromptEncoder` bound to its tokenizer. Our registry swaps `svc.tok` and other model fields but does not swap/reset the new `prompts` field. A CPU probe switched original to SC117: the service used the replacement tokenizer, while its prompt encoder still held the original tokenizer. This can encode with the wrong model's vocabulary when tokenizers differ and violates our cache-isolation requirement even when the two installed variants share token IDs. Integration must replace/rebuild this cache and restore the correct one on rollback, with a regression using distinguishable tokenizers. Also review `model_arch` initialization/default sampling for replacement services. This is an automatic-merge issue; the current live release has not received upstream's prompt cache.

All 110 existing combined MCP, chat-image, model-registry, chat-editing and reference tests passed in the isolated merged snapshot using the existing runtime virtual environment. They did not detect the cache-binding issue; the targeted probe above did. The first attempt with the system Python failed because upstream's newly imported tokenizer path needs `regex`; the existing runtime environment already has it. No package installation or environment modification was performed. Logs preserve both attempts and `model-cache-probe.py`/`.json`.

Evidence is local in `Strata-data\logs\upstream-review-20261017`: merge-tree output, merged source archive, pinned upstream documentation and merged mock test log. The snapshot uses CPU mocks only. No engine build, GPU benchmark, browser regression matrix or native handoff gate has been performed for this candidate. No local performance gain or deployment is claimed.

Recommendation: retain the current tested live release. Prepare a separate `update/upstream-0.1.45-20261017` integration branch, fix the confirmed cache-binding blocker, review sampling migration, complete mock/browser regressions, then coordinate a native CUDA build and Original/SC117 chat/vision/tools/images/handoff gate. Keep kernel opt-ins off until separately measured. Follow [FORK_WORKFLOW.md](FORK_WORKFLOW.md).
